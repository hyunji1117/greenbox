# 0008. 보관 기간에 맞춘 알림 시점과 장보기 전 요약

- 날짜: 2026-11-08
- 상태: 결정

## 배경

하루 요약은 모든 품목을 유통기한 3일 전부터 알렸다. 이틀 두는 생선은 등록하자마자 알림이 오고,
석 달 두는 냉동 품목은 3일 전에야 알게 돼 꺼내서 해동하고 먹을 계획을 세우기에 늦었다.

## 결정

- 품목마다 보관 기간(등록한 날부터 유통기한까지)에 따라 하루 요약에 넣기 시작하는 날을 정한다
  - 3일 이하: 당일 / 4~14일: 1일 전 / 15~60일: 3일 전 / 60일 넘음: 7일 전
  - 보관 기간은 새 칸 없이 등록일과 유통기한으로 계산해, 자동 작성(0006)과 직접 입력에 똑같이 적용된다
- 주간 요약을 "장보기 전 요약"으로 부른다. 고르는 요일은 장 보는 요일이고, 그날 정한 시각에
  일주일 안에 끝나는 품목을 모아 보낸다. 장 보러 나가기 전에 먹을 것과 살 것을 함께 정하게 한다
  - 가족 답변(주말 오후에 장 봄)에 맞춰 기본값 토요일 낮 12시를 그대로 둔다. 전날이 아니라 당일 나가기 전에 보낸다
  - 기존 요일과 시각 설정을 그대로 쓰므로 DB 변경이 없다

## 영향

- 홈의 "곧 먹어야 할 재료"(3일 안)와 레시피 추천 기준은 바꾸지 않는다. 알림만 기간에 맞춘다
