# 0007. 곧 먹어야 할 재료로 만드는 초간단 레시피

- 날짜: 2026-11-08
- 상태: 결정 (2026-11-09 방침 시행으로 모두에게 공개)

## 배경

유통기한 자동 작성(0006)으로 "곧 먹어야 할 재료"가 잘 잡히게 됐다. 알려 주기만 하면 사용자가 무엇을 해 먹을지 다시 고민해야 해서,
홈에서 그 재료로 15분 안에 만드는 요리를 바로 제안한다. 필요하면 가볍게 장을 보게 한다.

## 결정

- 홈 "바로 꺼내기" 아래에 추천 카드를 둔다. 곧 먹어야 할 재료(유통기한 3일 안)가 있을 때만 보인다
- 레시피 글은 Claude(`claude-sonnet-5-5`)가 만든다. 재료(있음 / 살 것 2개까지), 3~6단계, 익힘과 알레르기 주의
- 그림은 OpenAI 이미지 API(`gpt-image-2.6-flare`)로 만든다
  - 완성 사진 1장(중간 품질)은 레시피를 처음 열 때, 단계 그림(낮은 품질)은 사용자가 그 단계의 "그림 보기"를 눌렀을 때만
  - 그림 1장에 약 10초 걸린다
- 같은 재료 조합의 레시피와 그림은 저장해 다시 쓴다. 두 번째부터는 바로 뜨고 비용이 들지 않는다
  - 레시피에는 재료 이름만 저장하고 누가 만들었는지는 저장하지 않는다
  - "있음 / 살 것"은 저장된 값을 쓰지 않고 지금 냉장고와 집에 흔한 양념으로 다시 판단한다
- 사람마다 24시간에 레시피 5개, 그림 20장까지 새로 만든다. 그림은 우리 DB에 저장해 별도 저장 서비스를 쓰지 않는다
- 레시피를 다 만들면 쓴 곧 먹어야 할 재료를 "다 먹음"으로 바꿀 수 있다. 살 것은 한 번에 장보기 리스트에 담는다

## 방침과 공개 범위

레시피를 만들 때 냉장고 품목 이름을 Anthropic(미국)에, 요리 이름과 재료 이름을 OpenAI(미국)에 보낸다.
개인정보처리방침의 다음 버전(장보기 목록 서버 저장과 함께)에 넣고, 그 전까지는
`RECIPE_PREVIEW_USER_IDS`에 적은 사람(운영자 테스트 계정)에게만 연다. 시행 뒤 `RECIPES_ENABLED=true`로 모두에게 연다.

## 공개 방식 (2026-11-08 결정)

- 방침 2026-11-09 버전에 레시피를 넣는다. 레시피는 원하는 사람만 쓰는 기능이라 다시 동의받지 않고(방침 14조),
  처음 레시피를 만들거나 열 때 "품목 이름을 Anthropic, OpenAI(미국)로 보내요"에 한 번 동의를 받는다
  - 다시 동의받는 방식은 14조에 따라 7일 전 예고가 필요해 11월 15일에야 열 수 있어 택하지 않았다
- 시행 시각이 지나면 코드가 스스로 모두에게 연다 (`RECIPE_POLICY_VERSION`). 환경변수를 바꿀 필요가 없다
- 만들기 요청은 동의 표시(`agreed: true`)가 없으면 서버가 거절한다. 동의는 기기에 방침 버전으로 기억해, 레시피 내용이 바뀌면 다시 묻는다
- 저장된 레시피 그림을 여는 요청은 동의한 뒤에만 화면에서 보낸다 (서버는 사람별 동의를 따로 저장하지 않는다)

## 비용

- OpenAI 크레딧은 자동 충전을 끄고 $5만 충전했다. 잔액이 0이 되면 그림 만들기만 멈추고 레시피 글은 그대로 보인다
- 이미지 모델은 공식 문서에 토큰 단가만 있어, 장당 비용은 사용량 화면으로 확인해 갱신한다
